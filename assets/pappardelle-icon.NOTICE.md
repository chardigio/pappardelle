# Pappardelle icon

`pappardelle-icon.svg` and `pappardelle-icon-512.png` are the 🍝 (U+1F35D, spaghetti) emoji from Google's [Noto Emoji](https://github.com/googlefonts/noto-emoji), unmodified:

- `pappardelle-icon.svg`: `2D/svg/emoji_u1f35d.svg`
- `pappardelle-icon-512.png`: `2D/png/512/emoji_u1f35d.png`

Both come from release tag [`v2026-09-24-unicode18_0`](https://github.com/googlefonts/noto-emoji/tree/v2026-09-24-unicode18_0) (commit `e20cbc2b`).
